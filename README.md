A Python class hierarchy using an abstract `BasicShape`, `Circle`, `Rectangle`, and `Square`. Properties validate dimensions and update areas automatically.

## Run

Open `BasicShapes.pyproj` in Visual Studio with Python support, select a Python 3 interpreter, and run `main.py`. Use Test Explorer to run the tests.

From a terminal in this folder:

```text
python main.py
python -m unittest discover -s tests -v
```
